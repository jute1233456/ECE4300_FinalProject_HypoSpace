## 使用说明

`causal.json`、`3d.json`、`boolean.json` 为可直接加载的完整删减题库；`manifest.json` 包含每题参考解数、来源指纹、训练数据指纹和逐项删除原因。原27题未改，现有三题验证和任务序列未修改。

三题快速验证全部包含于本12题中。这里只去重题目族，不把一道题的多个机制解合并为一个解；解数沿用原任务定义。不同运算符集合或3D边界下的题采用保守家族排除，不声称所有题都在严格逻辑上完全相同。
