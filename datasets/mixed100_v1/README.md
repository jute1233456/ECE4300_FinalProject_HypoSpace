## 读取方式

不同难度的节点数、运算符等元数据不同，因此按easy、medium、supplemental分目录保存，不混用同一个metadata。manifest.json的每个job同时指定dataset_root、dataset、case_id。题号在不同难度可以相同，必须使用完整job ID。

manifest中baselines记录历史路径、模型、生成上限、覆盖率和题库指纹。原始题库、旧分数及正在运行的MCTS验证未改。补跑队列在主验证任务之外只领取剩余名额，不中断现有生成。
