## 衰减曲线（用户于2026-11-26要求先快后慢）

令 s 为已完成参数更新数，峰值 P=5e-5，总更新 T=40，warmup W=4。

- warmup阶段 0≤s≤W：`lr(s)=P*s/W`。
- 衰减阶段 W≤s≤T：令 `t=(s-W)/(T-W)`，使用 `lr(s)=P*(1-t)/(1+2*t)`，t限制在[0,1]。
- 比例函数 f(t)=(1-t)/(1+2t) 的一阶导数为 `-3/(1+2t)^2`，始终下降，但斜率绝对值逐渐变小；二阶导数 `12/(1+2t)^3>0`。起点与终点分别为P和0，没有最后一步额外硬切零。
- 调度器节点：更新完成4/13/22/31/40次时，lr分别为 `5e-5 / 2.5e-5 / 1.25e-5 / 5e-6 / 0`。这是更新后调度器节点，不是声称本次更新已经使用该值。
- 形状系数2是本组预先固定的实验设置，尚无证据证明最优；保持它不变以便复现。
- 小于1的幂指数并不自动代表越降越慢：`(1-t)^p` 在0<p<1时会越降越快，不符合要求；`1-t^p` 符合先快后慢但起点斜率发散。本组选择起点斜率有限的反比例形式。

## “前4次更新”和 batch 的含义

- microbatch=1：每次前向/反向计算处理1条SFT样本，样本不是整道题。
- gradient_accumulation_steps=16：通常累积16条样本才真正更新一次参数，有效batch=16。
- 双卡使用单进程 `device_map=auto` 分片一个模型，不是两个数据并行副本，因此有效batch不乘2。
- 309条每轮为19个完整窗口（19×16）和1个5条尾窗，总计20次更新；两轮为40次。
- 前4次更新对应前64条样本的计算。warmup按**参数更新次数**计，不按微批次数或题目数计。
- Transformers调度器的起点、更新后日志与实际本次使用的学习率存在一步口径区别；执行时应同时明确记录调度器节点或更新前学习率，不能把“更新后达到峰值”误写成该次更新已经使用峰值。

## 比较口径

- 当前基准：`1e-4`，无warmup，线性下降，2epoch。
- 新组：`5e-5`，4步warmup，先快后慢的归一化反比例下降，2epoch。
- 这是“降低学习率＋加入warmup＋改变衰减曲线”的**组合方案对照**，不能据此分别认定收益由其中某一个因素单独造成。暂不增加额外拆分组。
- 使用相同MCTS2.2提示词版本、评测题、搜索与生成预算，评测排除训练重合与等价题。比较协议成功率、有效候选率、解覆盖率，训练loss仅作辅助。
- 后续A+B完整数据实验若采用该方案，应保持两部分统一epoch次数，warmup按总参数更新数的10%重新计算；4步仅对应当前309条/2epoch方案。
